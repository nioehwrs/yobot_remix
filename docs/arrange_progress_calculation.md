# 排刀页面进度计算说明

## 概述

排刀页面用于计算公会战期间每天的Boss进度，帮助公会合理安排出刀计划。

---

## 基础常量

| 常量 | 值 | 说明 |
|------|-----|------|
| BLOCK_VALUE | 12 | 每一刀的价值单位，用于避免计算时出现小数，便于外推每轮或每天的总价值 |

---

## 配置参数

| 参数 | 变量名 | 默认值 | 说明 |
|------|--------|--------|------|
| 每天刀数 | x | 第1天: 14, 第2-5天: 18 | 每天计划打的刀数 |
| 每轮完整刀数 | a | 1 | 每轮的完整刀数 |
| 额外刀数分子 | b | 0 | 用于表示分数形式的额外刀数 |
| 额外刀数分母 | c | 2 | 用于表示分数形式的额外刀数 |

### 参数范围限制

| 参数 | 范围 |
|------|------|
| x | 5 ~ 40 |
| a | 1 ~ 6 |
| b | 0 ~ 3 |
| c | 2 ~ 4 |

**约束条件**: b < c（额外刀数必须小于分母）

---

## 修正参数（第2-5天）

修正参数用于微调第2-5天的进度，它不会占用每天总刀数（70或90）。

显示格式为：修正：[Ax]+[Bx]/[Cx]

| 参数 | 变量名 | 默认值 | 说明 |
|------|--------|--------|------|
| 整数修正 | ax | 0 | 对每天总刀数的整数修正 |
| 分子修正 | bx | 0 | 对每天总刀数的分子修正 |
| 分母修正 | cx | 2 | 对每天总刀数的分母修正 |

### 修正参数范围限制

| 参数 | 范围 |
|------|------|
| ax | -3 ~ 3 |
| bx | 0 ~ 3 |
| cx | 2 ~ 4 |

**约束条件**: bx < cx（与 b 和 c 的关系相同）

### 修正后的计算公式

修正后的每天总刀数：
```
F' = F + ax * BLOCK_VALUE + bx * BLOCK_VALUE / cx
```

当 ax=0, bx=0, cx=2 时，F' = F，结果与原来一样。

**注意**: 修正参数仅在第2-5天有效，第1天不显示修正参数。

---

## 计算公式

### 基础公式

```
F = x * BLOCK_VALUE                           // 每天总刀数（块单位）
D = a * BLOCK_VALUE + b * BLOCK_VALUE / c     // 每轮刀数（块单位）
```

### 第1天计算

#### 基础数值
```
G = floor(F / D)    // 完整轮数
H = F % D           // 余数（未完成一轮的部分）
J = 23              // 起始周目
```

#### 每轮（完整轮）的块分解

对于第 i 轮（i = 0, 1, 2, ..., G-1）：

```
P = BLOCK_VALUE - ((D * i - 1) % BLOCK_VALUE) - 1   // 起始部分块
Q = floor((D - P) / BLOCK_VALUE)                     // 中间完整块数量
R = (D - P) % BLOCK_VALUE                            // 末尾部分块
```

**块的宽度计算**:
- P块宽度: P / BLOCK_VALUE
- Q块: 每个块宽度为1（完整块）
- R块宽度: R / BLOCK_VALUE

#### 最后一轮（余数部分）的块分解

```
S = min(BLOCK_VALUE - ((D * G - 1) % BLOCK_VALUE) - 1, H)  // 起始部分块
T = floor((H - S) / BLOCK_VALUE)                            // 中间完整块数量
U = (H - S) % BLOCK_VALUE                                   // 末尾部分块
```

---

### 第2-5天计算

#### 基础数值

```
fullCyclesPrev = Σ(前 d 天的 G 值), d = 1 到 day-1    // 之前累计的完整轮数
HPrev = 前一天的 H 值                                  // 前一天的余数

J = fullCyclesPrev + 22 + (day - 1)    // 起始周目
G = floor((F + HPrev) / D) - 1         // 当天完整轮数
K = D - HPrev                          // 补齐前一天余数所需刀数
H = (F + HPrev) % D                    // 当天余数
```

#### 第一轮（含前一天余数）的块分解

```
S = min(BLOCK_VALUE - ((D * (J + 1) - HPrev - 1) % BLOCK_VALUE) - 1, HPrev)
T = floor((HPrev - S) / BLOCK_VALUE)
U = (HPrev - S) % BLOCK_VALUE

Y = floor(K / BLOCK_VALUE)    // 当天新刀的完整块
Z = K % BLOCK_VALUE           // 当天新刀的部分块
```

**块的类型**:
- S, T, U 块: 灰色（gray）- 表示前一天遗留的部分
- Y, Z 块: 正常色（full/partial）- 表示当天的进度

#### 中间轮（完整轮）的块分解

对于第 i 轮（i = 0, 1, 2, ..., G-1）：

```
P = BLOCK_VALUE - ((D * (i + 1) - HPrev - 1) % BLOCK_VALUE) - 1
Q = floor((D - P) / BLOCK_VALUE)
R = (D - P) % BLOCK_VALUE
```

#### 最后一轮（余数部分）的块分解

```
S2 = min(BLOCK_VALUE - ((D * (G + 1) - HPrev - 1) % BLOCK_VALUE) - 1, H)
V = floor((H - S2) / BLOCK_VALUE)
U2 = (H - S2) % BLOCK_VALUE
```

## 变量含义汇总

| 变量 | 含义 |
|------|------|
| F | 每天总刀数（块单位） |
| D | 每轮刀数（块单位） |
| G | 完整轮数 |
| H | 余数（未完成一轮的部分） |
| J | 起始周目 |
| K | 补齐前一天余数所需刀数 |
| HPrev | 前一天的余数 |
| fullCyclesPrev | 之前累计的完整轮数 |

### 块分解变量

| 变量 | 含义 |
|------|------|
| P | 每轮起始的部分块 |
| Q | 每轮中间的完整块数量 |
| R | 每轮末尾的部分块 |
| S, S2 | 最后一轮起始的部分块 |
| T, V | 最后一轮中间的完整块数量 |
| U, U2 | 最后一轮末尾的部分块 |
| Y | 第2-5天第一轮中当天新刀的完整块 |
| Z | 第2-5天第一轮中当天新刀的部分块 |

## 预期刀数

| 天数 | 预期总刀数 (E) |
|------|----------------|
| 第1天 | 70 |
| 第2-5天 | 90 |

预期总刀数 = 5个Boss的 x 值之和

## 示例计算

### 第1天示例

假设配置：
- x = 14（刀）
- a = 1, b = 0, c = 2

计算：
```
F = 14 * 12 = 168
D = 1 * 12 + 0 = 12
G = floor(168 / 12) = 14
H = 168 % 12 = 0
J = 23
```

结果：第1天从周目23开始，打14轮完整轮，无余数。

### 第2天示例

假设配置：
- x = 18（刀）
- a = 1, b = 1, c = 2
- 前一天 HPrev = 0, fullCyclesPrev = 14

计算：
```
F = 18 * 12 = 216
D = 1 * 12 + 1 * 12 / 2 = 18
G = floor((216 + 0) / 18) - 1 = 11
H = (216 + 0) % 18 = 0
J = 14 + 22 + 1 = 37
K = 18 - 0 = 18
```

结果：第2天从周目37开始，打11轮完整轮，无余数。
